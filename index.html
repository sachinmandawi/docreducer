The Engineering Behind Lossless & Lossy Image Compression

How SahiKagaz delivers razor-sharp visual fidelity while slashing file sizes by over 95%:

1. Stripping Redundant EXIF & Geolocation Metadata

Modern smartphones (iPhones, Samsung, Google Pixel, OnePlus) capture photos accompanied by hundreds of kilobytes of invisible metadata. This EXIF container includes GPS geographic coordinates, camera lens serial numbers, exposure histograms, device identifiers, and embedded low-resolution thumbnail duplicates. SahiKagaz strips away all non-visual metadata during the initial canvas ingest, instantly shaving off 15% to 25% of the file size without modifying a single image pixel.

2. Discrete Cosine Transform (DCT) & 4:2:0 Chroma Subsampling

Human visual biology perceives variations in brightness (luminance or Y channel) with significantly greater sensitivity than minute variations in color tint (chrominance or Cb/Cr channels). Our compression engine transforms spatial pixel matrices into frequency domains via Discrete Cosine Transform. By implementing YCbCr 4:2:0 subsampling, high-frequency luminance details in handwritten signatures, facial features, and passport boundaries are preserved with maximum fidelity while imperceptible color noise is mathematically quantized.

3. Automated 8-Stage Binary Search Algorithm for Exact Target KB

Most legacy web tools force candidates to experiment with trial-and-error quality sliders (e.g. 60%, 45%, 30%), often resulting in either oversized files that get rejected by recruitment portals or overly degraded blurry images. SahiKagaz solves this problem with an autonomous 8-iteration binary search algorithm. It dynamically computes test compression blobs directly in client RAM, adjusting quality factors and bounding boxes to guarantee the maximum possible resolution that remains strictly within your target byte ceiling (e.g., ≤ 20 KB or ≤ 50 KB).

4. Optimal File Format Matrix: Choosing the Right Format

Choosing the correct output format ensures seamless submission and fast loading:

  • JPEG / JPG: The universal standard demanded by 99% of government examination forms (SSC, UPSC, Banking, NEET). Offers maximum compression ratios for photographic portraits and scanned documents.
  • WebP: Developed by Google, WebP delivers up to 35% smaller file sizes than JPEG at identical visual quality. Best suited for websites, mobile applications, and web publishing.
  • PNG: A lossless raster format engineered for diagrams, vector signatures with transparent backgrounds, and technical charts where sharp pixel-perfect edges are mandatory.
  • PDF Document: The standard format for single-page identity card submissions, printable certificates, and official document archives.
